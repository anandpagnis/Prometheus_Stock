## Backend

### `HttpClient.Timeout = 15s` on the Yahoo typed client

`MarketDataServiceCollectionExtensions.cs` sets a flat 15-second `HttpClient.Timeout`
on the Yahoo client. An earlier iteration used
`AddStandardResilienceHandler()` (retry + circuit breaker + its own timeouts); that
was removed to keep the MVP surface small (`PROMPT_LOG.md` #008), so this plain socket
timeout is now the only bound on a hung upstream call. Moving it (and a real retry
policy) into configuration is a listed growth item.

### Test fixtures

- `PrometheusStock.Tests.csproj` gained
  `<None Update="Fixtures\**\*.json" CopyToOutputDirectory="PreserveNewest" />` so
  fixture JSON is copied next to the test assembly and read at runtime.
- `Fixtures/yahoo-chart-5d.json` — a **real** capture from
  `query1.finance.yahoo.com/v8/finance/chart/TSLA?interval=15m&range=5d`, hand-edited to
  null the `open/high/low/close/volume` rows at indices 5, 6 and 40. `5d` (not `1mo`)
  keeps the file small enough that the mapper/aggregator assertions are checkable by
  hand; the nulled rows exercise the gap-skipping path (117 timestamps → 114 bars).
- `Fixtures/yahoo-chart-dst.json` — hand-authored (a real Nov-2025 15-minute capture is
  impossible: Yahoo only serves 15m data for the last 60 days). Five bars straddling
  the 02 Nov 2025 `America/New_York` EDT→EST change, with `meta.gmtoffset` left at the
  single EDT value for the whole payload so a client that trusts that scalar instead of
  converting each timestamp in the exchange zone fails the test.
